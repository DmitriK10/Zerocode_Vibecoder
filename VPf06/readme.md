# 🤖 Telegram Bot with Short and Long Memory

**Telegram бот с короткой (диалоговой) и долгой (векторной) памятью.**

Бот умеет:
- вести диалог, запоминая последние N сообщений (короткая память);
- загружать документы (PDF, TXT, DOCX) и индексировать их в векторную базу ChromaDB;
- отвечать на вопросы, используя контекст из загруженных документов (долгая память);
- комбинировать оба типа памяти для связных и фактологически точных ответов.

## 📦 Возможности

- 📄 Загрузка документов (PDF, TXT, DOCX) и индексация через OpenAI Embeddings
- 🧠 Короткая память – хранит последние 10 сообщений диалога (настраивается)
- 🗂️ Долгая память – векторное хранилище ChromaDB с поиском по смыслу
- 💬 Ответы с учётом истории и загруженных документов
- 🔌 Поддержка OpenAI API (через официальный SDK) или GenAPI (через REST)
- 🌐 Работа через прокси для Telegram API (опционально)
- 💰 Курс валют (USD, EUR, RUB и другие)
- 🖼 Генерация QR-кодов

🧠 Как работает память
Короткая память (диалог)
Хранит последние CONTEXT_LIMIT сообщений (по умолчанию 10) для каждого пользователя.

Реализована в ContextManager (оперативная память).

Используется для поддержания связности разговора.

Долгая память (документы)
При загрузке документа текст извлекается, разбивается на чанки с перекрытием.

Для каждого чанка вычисляется эмбеддинг через OpenAI Embeddings.

Чанки и векторы сохраняются в ChromaDB с метаданными пользователя.

При вопросе выполняется семантический поиск, релевантные фрагменты добавляются в системный промпт.

Объединённый подход
В запросе к LLM передаются:

системное сообщение с инструкцией и найденным контекстом из документов;

история диалога (короткая память);

текущий вопрос пользователя.

Модель генерирует ответ, учитывая все источники.

🤖 Команды бота
/start – приветственное сообщение и справка.

/reset – очистить короткую память (историю диалога) для текущего пользователя.

/cleardocs – удалить все загруженные документы пользователя из долгой памяти (векторной базы).

Любое текстовое сообщение – запрос к модели (используется память).

Загрузка документа – автоматическая индексация в векторную базу (поддерживаются PDF, TXT, DOCX).

❗ Возможные проблемы и решения
SSL-ошибка при установке зависимостей
Используйте флаги --trusted-host или установите chromadb без бинарных колес:

bash
pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org -r requirements.txt
Ошибка соединения с Telegram (прокси)
Если вы используете прокси (TELEGRAM_API_BASE_URL) и получаете httpx.ConnectError, проверьте доступность прокси-сервера. Временно отключите прокси, закомментировав соответствующую строку в .env, или увеличьте таймауты в bot.py.

ChromaDB не запускается на Windows
Убедитесь, что установлены Microsoft C++ Build Tools. Альтернативно можно использовать faiss-cpu (требуется модификация кода).
