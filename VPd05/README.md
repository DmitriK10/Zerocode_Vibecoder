# Currency Travel Bot 💰✈️

Telegram-бот для управления финансами в путешествиях. Позволяет создавать поездки, конвертировать валюты по реальному курсу (API exchangerate.host), отслеживать расходы и баланс в двух валютах.

## Возможности

- ✅ Создание путешествий с автоматическим определением валют по странам (или ручным вводом)
- ✅ Получение актуального курса через API exchangerate.host
- ✅ Возможность ручной установки курса (например, по местному обменнику)
- ✅ Учёт расходов в валюте страны пребывания с автоматической конвертацией в домашнюю валюту
- ✅ Хранение баланса в обеих валютах
- ✅ История всех расходов с датами
- ✅ Переключение между несколькими путешествиями
- ✅ Inline-клавиатура для удобной навигации + поддержка слэш-команд
- ✅ Локальное хранение данных в SQLite

## Команды

- `/start` – приветствие и главное меню
- `/newtrip` – создание нового путешествия
- `/switch` – выбор активного путешествия
- `/balance` – показать текущий баланс
- `/history` – история расходов
- `/setrate` – изменить курс вручную
