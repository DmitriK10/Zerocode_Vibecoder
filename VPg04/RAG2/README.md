# RAG-агент с Pinecone, обработкой URL и API-запросами

## Описание
Агент, реализующий подход **Retrieval-Augmented Generation (RAG)**.  
Он подключается к векторному хранилищу **Pinecone**, позволяет загружать содержимое веб-страниц по URL, разбивать на чанки, индексировать и затем отвечать на вопросы, используя найденные документы в качестве контекста. Также агент умеет выполнять внешние API-запросы (например, получать случайный факт о котах) через инструменты LangChain.

4. Запуск тестовой проверки
bash

Вы должны увидеть:

Ответ на вопрос "Что такое RAG?" (если база пуста – будет сказано об отсутствии информации),

5. Запуск Telegram-бота
bash
python telegram_bot.py
Бот будет отвечать на команды:

/search <вопрос> – найти ответ в базе знаний.

/add_url <url> – загрузить и проиндексировать содержимое страницы.

/catfact – получить случайный факт о котах.

Любое текстовое сообщение – выполнит поиск с RAG и даст ответ.

Принципы проектирования
SRP (Single Responsibility Principle) – каждый класс отвечает за одну задачу (эмбеддинги, работа с Pinecone, парсинг URL, поиск, генерация, API-инструмент).

DIP (Dependency Inversion Principle) – зависимости внедряются через конструкторы, что позволяет легко заменять реализации (например, заменить Pinecone на другое хранилище).

Ограничения и особенности
Используется модель gpt-3.5-turbo-16k (не выше).

Все запросы к OpenAI проходят через прокси proxypi.ru (указан в OPENAI_BASE_URL), если вы используете прямой OpenAI – измените базовый URL.

Для обхода SSL-ошибок при загрузке некоторых сайтов (например, cloud.ru) в коде используется httpx с verify=False. Это безопасно только для отладки; в продакшене следует настроить корректные сертификаты.

Возможные проблемы и решения
Ошибка SSLEOFError при загрузке URL
Замените requests на httpx с verify=False – это уже реализовано в коде.

Ошибка PineconeApiValueError: name length > 45
Убедитесь, что имя индекса в .env короткое (например, zerovpg02). В коде добавлена проверка и автоматическая очистка.

Ошибка импорта create_agent
В некоторых версиях LangChain аргумент называется system_prompt. Код уже адаптирован под вашу версию (1.3.14). При обновлении пакетов проверьте совместимость.

Вклад и доработка
Для добавления новых инструментов создайте статический метод с декоратором @tool в классе APITool и добавьте его в список tools в _build_agent().

Для изменения размера чанков или количества возвращаемых документов измените параметры chunk_size, chunk_overlap и k при инициализации соответствующих классов.
