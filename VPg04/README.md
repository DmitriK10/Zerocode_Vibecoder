# RAG Agent with Telegram Bot

Данный проект реализует RAG-агента с интерфейсом Telegram-бота. Используются Pinecone (векторное хранилище), OpenAI Embeddings и языковая модель `gpt-3.5-turbo-16k` через прокси `proxypi.ru`.

## Возможности
- Добавление веб-страниц в базу знаний по URL.
- Поиск по базе знаний.
- Ответы на вопросы с использованием извлечённого контекста.
- Получение случайных фактов о кошках из внешнего API.
- Интерфейс Telegram-бота.

## Требования
- Python 3.8+
- Podman (или Docker) для контейнеризации (опционально)
- Аккаунт Pinecone и созданный индекс
- API-ключ OpenAI с доступом к `gpt-3.5-turbo-16k` через `proxypi.ru`
