# Vibecoding – Кейс-промпты

Проект демонстрирует использование заранее подготовленных промптов для трёх задач:
- Резюме текста
- Генерация структуры кода
- Планирование задач

## Установка
1. Установите зависимости: `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env` и заполните свои данные.
3. Запустите: `python src/main.py`

## Настройка окружения (`.env`)
- `OPENAI_API_KEY` – ваш ключ от OpenAI или ProxyAPI.
- `OPENAI_MODEL` – модель (по умолчанию `openai/gpt-4o-mini`).
- `LOG_LEVEL` – уровень логирования (`DEBUG`, `INFO`, `WARNING`, `ERROR`).

## Использование
Следуйте инструкциям в консоли. Выберите кейс, введите текст, укажите температуру.
При желании включите потоковый вывод и сохраните результат в файл.
