# 🤖 Task Bot — Телеграм-бот для управления задачами

## 📖 Описание

`Task Bot` — это асинхронный телеграм-бот, разработанный на библиотеке `aiogram`, который позволяет пользователям создавать, просматривать и выгружать свои задачи в формате CSV. Бот использует машину состояний (FSM) для пошагового добавления задач, а все данные сохраняются в локальной базе данных SQLite.

Проект написан с соблюдением принципов чистой архитектуры: логика обработки команд вынесена в отдельный модуль, работа с базой данных инкапсулирована в репозиторий, а конфигурация централизована.

## 🎯 Цель проекта

*   Освоить создание асинхронных телеграм-ботов на библиотеке `aiogram` версии 3.x.
*   Реализовать машину состояний (FSM) для пошагового сбора данных от пользователя.
*   Отработать паттерн «Репозиторий» для абстрагирования работы с базой данных.
*   Научиться генерировать и отправлять пользователю файлы (CSV-экспорт).

## ✨ Функциональные возможности

*   **Добавление задачи:** Пошаговый процесс через FSM: ввод текста → выбор статуса → выбор категории.
*   **Просмотр всех задач:** Команда `/list` выводит список всех задач пользователя с их статусами и категориями.
*   **Экспорт в CSV:** Команда `/list_csv` генерирует CSV-файл со всеми задачами пользователя и отправляет его в чат.
*   **Интерактивные клавиатуры:** Для выбора статуса и категории используются кнопки, что упрощает взаимодействие.
*   **Автоматическая миграция БД:** При первом запуске таблица создаётся автоматически, а при добавлении новых полей — расширяется.

## 🛠 Использованные технологии

*   **Язык программирования:** Python 3.10+
*   **Библиотеки:**
    *   `aiogram==3.4.1` — фреймворк для создания телеграм-ботов.
    *   `aiosqlite==0.19.0` — асинхронный драйвер для SQLite.
*   **База данных:** SQLite (встроенная, файл `tasks.db`).
*   **Архитектура:** Асинхронное программирование, паттерн «Репозиторий», FSM (Finite State Machine).

## 🏗 Архитектура проекта

```mermaid
graph TD
    User[Пользователь] -->|Команды| Bot[Telegram Bot API]
    Bot -->|Обработка| Handlers[handlers.py]
    Handlers -->|CRUD| Repository[TaskRepository]
    Repository -->|SQL| Database[(tasks.db)]
    Handlers -->|Генерация CSV| Utils[utils.py]
    Utils -->|Создаёт файл| CSV[CSV-файл]
    Handlers -->|Отправляет файл| User
main.py — Точка входа. Инициализирует бота, диспетчер и запускает поллинг.

handlers.py — Содержит все обработчики команд и состояний FSM. Здесь реализована вся бизнес-логика взаимодействия с пользователем.

database.py — Реализует класс TaskRepository, который инкапсулирует все операции с базой данных (создание таблицы, добавление, получение задач).

config.py — Централизованное хранение конфигурации: токен бота, пути к базе данных и папке для экспорта.

utils.py — Вспомогательные функции, в данном случае — генерация CSV-файла из списка задач.

requirements.txt — Список зависимостей проекта.

🚀 Установка и запуск
Перейдите в папку проекта:

bash
cd VPb06/task_bot
Создайте виртуальное окружение и активируйте его:

bash
python -m venv venv
source venv/bin/activate  # для Linux/macOS
# или
venv\Scripts\activate     # для Windows
Установите зависимости:

bash
pip install -r requirements.txt
Настройте токен бота:

Откройте файл config.py.

Замените значение переменной BOT_TOKEN на ваш токен, полученный от @BotFather в Telegram.

Важно: Никогда не публикуйте токен в открытом доступе! Рекомендуется использовать переменные окружения.

Запустите бота:

bash
python main.py
В Telegram найдите своего бота и отправьте команду /start.

💻 Пример использования
text
👋 Привет! Я бот для хранения задач.

Доступные команды:
/add - добавить новую задачу (текст, статус, категория)
/list - показать все ваши задачи
/list_csv - выгрузить все задачи в CSV-файл
Процесс добавления задачи:

Пользователь вводит /add.

Бот запрашивает текст задачи.

Пользователь вводит текст (например, «Сдать отчёт по проекту»).

Бот показывает кнопки для выбора статуса: «Новая», «В работе», «Завершена», «Отложена».

Пользователь выбирает статус (например, «В работе»).

Бот показывает кнопки для выбора категории: «Работа», «Личное», «Учеба», «Дом», «Общая».

Пользователь выбирает категорию (например, «Работа»).

Бот сохраняет задачу и подтверждает: «✅ Задача добавлена!».
