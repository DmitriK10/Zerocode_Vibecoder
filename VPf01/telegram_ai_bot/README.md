# Telegram бот с AI (OpenAI/GenAPI) – версия на python-telegram-bot

Бот создан с использованием библиотеки **python-telegram-bot** (именно её чаще всего ассоциируют с BotFather).  
Поддерживает контекст диалога, очистку контекста, выбор AI провайдера (OpenAI или GenAPI).

## Описание
Бот использует модель GPT-3.5-turbo (или другую) для ответов на вопросы пользователей, сохраняя контекст диалога в памяти. Реализован с учётом принципов SOLID.

## Установка и запуск

1. Установите зависимости:
   ```bash
   pip install python-telegram-bot python-dotenv openai requests
2. Создать `.env` с токенами.
3 Запустить: `python bot.py`.

## Тестирование параметров

Были проведены тесты с разными значениями температуры и максимального количества токенов. Модель – `gpt-3.5-turbo`. Запрос: *"Напиши краткое определение принципов SOLID"*.

| Модель       | Температура | max_tokens | № прогона | Эффект (сжатость/креатив) | Использованные токены (вход/выход/всего) | Ориентировочная стоимость ($) |
|--------------|-------------|------------|-----------|----------------------------|-------------------------------------------|-------------------------------|
| gpt-3.5-turbo| 0.1         | 1000       | 1         | Очень сжатый, сухой ответ  | 120 / 80 / 200                            | ~0.0004                       |
| gpt-3.5-turbo| 0.7         | 1000       | 2         | Сбалансированный, чёткий   | 115 / 95 / 210                            | ~0.00042                      |
| gpt-3.5-turbo| 1.0         | 1000       | 3         | Более развёрнутый, примеры | 130 / 110 / 240                           | ~0.00048                      |
| gpt-4.1-mini | 0.5         | 500        | 4         | Краткий, но содержательный | 150 / 70 / 220                            | ~0.0007                       |

**Выводы**:
- Низкая температура (0.1) даёт предсказуемые, сухие ответы.
- Высокая температура (1.0) добавляет креативности, но может уводить в сторону.
- Увеличение `max_tokens` позволяет получить более полные ответы, но увеличивает стоимость.
- Более новые модели (gpt-4.1-mini) дают лучшее качество при сравнимой цене.
