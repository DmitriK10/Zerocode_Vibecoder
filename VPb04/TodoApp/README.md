# 📋 TodoApp — Система управления задачами (ООП)

## 📖 Описание

`TodoApp` — это консольное приложение на Python, реализующее систему управления задачами с использованием принципов объектно-ориентированного программирования (ООП). Проект позволяет создавать пользователей, проекты (списки задач) и сами задачи, управлять их статусом и сериализовать данные для сохранения.

Ключевая особенность этого проекта — **архитектурный подход**: сначала была разработана детальная структура классов и их взаимодействий, и только затем написан код[reference:1][reference:2].

## 🎯 Цель проекта

*   Закрепить навыки объектно-ориентированного проектирования на практике.
*   Реализовать модель данных с соблюдением принципов SOLID.
*   Отработать механизмы сериализации объектов в словари и JSON для последующего сохранения.
*   Изучить подход к разработке через детальное описание архитектуры (Prompt Engineering).

## ✨ Функциональные возможности

*   **Управление пользователями:** Создание пользователя с уникальным идентификатором (UUID).
*   **Управление проектами:** Создание проектов (например, «Работа», «Личное») в рамках пользователя, удаление и поиск проектов.
*   **Управление задачами:** Добавление, удаление и поиск задач внутри проекта. Задача содержит название, описание, статус выполнения, срок выполнения и дату создания.
*   **Изменение статуса задачи:** Возможность отметить задачу как выполненную или невыполненную.
*   **Сериализация данных:** Преобразование объектов в словари (`to_dict()`) и обратное восстановление (`from_dict()`), что позволяет легко сохранять данные в JSON[reference:3][reference:4].
*   **Демонстрационный режим:** Встроенная функция `main()` показывает пример создания пользователя, проекта, задач и сериализации данных[reference:5].

## 🛠 Использованные технологии

*   **Язык программирования:** Python 3.10+
*   **Стандартные библиотеки:** `uuid` (генерация уникальных ID), `datetime` (работа с датами), `json` (сериализация), `dataclasses` (опционально).
*   **Архитектура:** Принципы SOLID, абстракция, инкапсуляция.

## 🏗 Архитектура проекта

Проект построен на трёх основных сущностях, взаимодействующих по иерархическому принципу[reference:6]:

```mermaid
graph TD
    User -->|содержит| Project
    Project -->|содержит| Task
User (Пользователь): Владелец проектов. Содержит список проектов. Умеет создавать, удалять и находить проекты.

Project (Проект/Список задач): Контейнер для группы задач. Содержит список задач. Умеет добавлять, удалять и находить задачи, а также получать списки выполненных/невыполненных задач.

Task (Задача): Минимальная единица. Содержит название, описание, статус, срок выполнения и дату создания. Умеет менять свой статус, описание и срок.

Все классы реализуют методы сериализации (to_dict() и from_dict()), что обеспечивает гибкость при работе с различными хранилищами данных.

🚀 Установка и запуск
Перейдите в папку проекта:

bash
cd VPb04/TodoApp
Убедитесь, что у вас установлен Python 3.10 или выше.

Запустите демонстрационный пример:

bash
python main.py
После запуска вы увидите пример создания пользователя, добавления проектов и задач, а также вывод сериализованных данных в формате JSON.

💻 Пример использования (из кода)
python
from main import User, Project, Task

# Создаём пользователя
user = User(username="Алексей")

# Создаём проект
project = Project(name="Работа")
user.create_project(project)

# Добавляем задачи
task1 = Task(title="Написать отчёт", description="Подготовить ежеквартальный отчёт")
task2 = Task(title="Созвон с клиентом", description="Обсудить детали проекта")
project.add_task(task1)
project.add_task(task2)

# Отмечаем задачу выполненной
task1.mark_completed()

# Сериализуем данные
user_data = user.to_dict()
print(user_data)  # Вывод в JSON-подобном формате
