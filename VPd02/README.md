# Конвертер валют с кэшированием (Exchange Rate API)

Проект представляет собой консольное приложение на Python для получения актуальных курсов валют и конвертации сумм с использованием публичного API [open.er-api.com](https://open.er-api.com). Реализовано кэширование ответов в JSON-файл с проверкой возраста (по умолчанию 24 часа). Код написан в соответствии с принципами SOLID и разделён на модули для обеспечения гибкости и переиспользования.

## Возможности

- Получение курсов валют для любой базовой валюты, поддерживаемой API (более 160 валют).
- Вывод курсов для предустановленного списка валют (RUB, EUR, GBP).
- Конвертация произвольной суммы из одной валюты в другую.
- Кэширование ответа API в файл `currency_rate.json` (рядом со скриптом).
- Автоматическое использование кэша, если он был создан менее 24 часов назад (экономия лимитов бесплатного API).
- Обработка ошибок сети, недоступности API, неверных кодов валют – без вывода стектрейсов, с понятными сообщениями для пользователя.
- Полные абсолютные пути к файлам (через `pathlib.Path(__file__).resolve().parent`), что гарантирует работу из любой директории.

## Детали реализации
1. Работа с API (api_client.py)
Функция get_currency_rates(base: str) -> Optional[Dict] формирует URL https://open.er-api.com/v6/latest/{base}.

Выполняет GET-запрос с таймаутом 10 секунд.

Проверяет статус-код и наличие поля "result": "success".

Возвращает словарь с полным ответом API (содержит "rates", "base_code", "time_last_update_utc" и др.) или None при ошибке.

2. Кэширование (storage.py)
Абсолютный путь к файлу кэша вычисляется через Path(__file__).resolve().parent / "currency_rate.json". Это гарантирует, что независимо от текущей рабочей директории файл будет создан/прочитан в папке со скриптами.

save_to_file использует json.dump(..., ensure_ascii=False, indent=4) для человеко-читаемого формата.

read_from_file возвращает None, если файла нет или он повреждён.

is_cache_fresh проверяет возраст файла (по умолчанию 24 часа) через path.stat().st_mtime.

3. Пользовательский интерфейс (cli.py)
get_available_currencies извлекает список валют из поля "rates" (именно так называется поле в ответе open.er-api.com, а не conversion_rates).

validate_currency проверяет наличие кода в списке.

convert_amount выполняет конвертацию по формуле сумма / курс_исходной * курс_целевой и округляет до 4 знаков.

display_rates выводит курсы для заданного набора валют.

run_converter реализует интерактивный ввод и вызов конвертации.

4. Оркестрация (currency.py)
get_currency_data реализует логику «кэш или свежие данные»:

Пытается прочитать кэш.
Если кэш существует, соответствует запрошенной базовой валюте и свежий (менее 24 часов), возвращает его.
Иначе выполняет запрос к API.
Если API вернул ошибку, но есть старый кэш – использует его с предупреждением.
Если нет ни API, ни кэша – завершает программу с сообщением.
После получения данных извлекает поле "rates" (обратите внимание – не "conversion_rates"!) и передаёт его в функции отображения и конвертации.

5. Обработка ошибок
Отсутствие модуля requests: при запуске без установки библиотеки программа выдаст ModuleNotFoundError. Решение: pip install requests.

Ошибка сети (нет интернета, таймаут): api_client.py ловит requests.RequestException и возвращает None. currency.py в этом случае попытается использовать кэш.

Неверный код валюты (например, XXX): при попытке использовать его как базовый или в конвертации будет выведено сообщение «Ошибка: валюта 'XXX' не поддерживается» и показан список доступных валют (первые 20).

Повреждённый JSON-файл кэша: storage.read_from_file ловит исключение и возвращает None, затем программа обратится к API.

## Возможные ошибки и их обработка
Ситуация	Сообщение пользователю	Действие программы
Нет модуля requests	ModuleNotFoundError (вывод Python)	Завершение, требуется установка
Нет интернета / API недоступен	[Ошибка сети] Не удалось соединиться с API: ...	Использует старый кэш, если есть
API вернул статус не 200	[Ошибка HTTP] Статус 404 для USD	Пытается использовать кэш
Неверный код валюты	Ошибка: валюта 'XXX' не поддерживается.	Возврат к вводу или завершение
Файл кэша повреждён	[Ошибка] Не удалось прочитать ...	Запрашивает свежие данные из API
Базовая валюта не найдена в ответе	Ошибка: валюта 'USD' не найдена в списке поддерживаемых.	Завершение (следует повторить с другой валютой)
Ни одна ошибка не приводит к выводу полного стектрейса – все исключения перехватываются и преобразуются в понятные сообщения.
