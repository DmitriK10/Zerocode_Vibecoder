📘 Telegram-бот с векторной памятью (Pinecone + OpenAI)
Этот проект представляет собой Telegram-бота с долговременной векторной памятью. Бот использует Pinecone для хранения эмбеддингов сообщений пользователей и OpenAI (через прокси proxyapi.ru) для генерации ответов и создания эмбеддингов. Ключевая особенность – умная фильтрация дубликатов на основе косинусного сходства: если новое сообщение по смыслу похоже на уже сохранённое, бот обновляет существующую запись, а не создаёт новую.

🚀 Возможности
🤖 Общение с пользователем в Telegram.

🧠 Хранение истории диалогов в векторной базе Pinecone.

🔍 Поиск релевантного контекста из памяти при каждом ответе.

🧮 Автоматическое обнаружение дубликатов через косинусное сходство (порог настраивается).

🔄 Обновление существующих записей вместо создания дублей.

📦 Гибкая настройка через переменные окружения (.env).

📐 Соблюдение принципов SOLID (SRP и DIP).

🛠 Установка и настройка
1. Клонируйте репозиторий
bash
git clone <url-репозитория>
cd zero_vpg_bot
2. Создайте и активируйте виртуальное окружение
bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate
3. Установите зависимости
bash
pip install -r requirements.txt
4. Настройте переменные окружения
Скопируйте файл .env.example в .env и заполните его реальными данными:

bash
# OpenAI / Proxy
OPENAI_API_KEY=sk-ваш_ключ
OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1
OPENAI_MODEL=gpt-3.5-turbo-16k

# Pinecone
PINECONE_API_KEY=ваш_ключ_pinecone
PINECONE_INDEX_NAME=zerovpg02
PINECONE_ENVIRONMENT=us-east-1

# Telegram
TELEGRAM_BOT_TOKEN=ваш_токен_бота

# Порог косинусного сходства (0..1)
SIMILARITY_THRESHOLD=0.5
▶️ Запуск
Запустите бота командой:

bash
python bot.py
В консоли появится сообщение Бот запущен.... После этого вы можете отправлять сообщения вашему боту в Telegram.

🧪 Проверка работы фильтрации дубликатов
Отправьте боту два похожих по смыслу сообщения, например:

Я хочу полететь на Марс

Я полечу на Марс

В консоли вы увидите:

text
[Память] Действие: inserted, сходство: None   # для первого
[Память] Действие: updated, сходство: 0.747   # для второго (сходство выше порога)
Если второе сообщение распознано как дубликат – фильтрация работает.

🧠 Принцип работы
Пользователь отправляет сообщение боту.

Бот создаёт эмбеддинг (векторное представление) текста через OpenAI.

Выполняется поиск в Pinecone – ищется самый похожий вектор.

Если найденный вектор имеет косинусное сходство ≥ порога (по умолчанию 0.5), новое сообщение считается дубликатом – существующая запись обновляется (действие updated).

Если сходство ниже порога – сообщение сохраняется как новая запись (действие inserted).

Бот также извлекает контекст из памяти (3 наиболее релевантных сообщения) и передаёт его в OpenAI для генерации ответа.

Ответ отправляется пользователю.

🔧 Контейнеризация (Podman/Docker)
В проекте есть Dockerfile. Для сборки образа выполните:

bash
podman build -t zero-vpg-bot .
Запуск контейнера:

bash
podman run --env-file .env zero-vpg-bot
Примечание: Если на Windows возникают сетевые проблемы (SSL, DNS), запускайте бота напрямую через python bot.py – это полностью допустимый способ эксплуатации.

📌 Принципы SOLID в проекте
Single Responsibility Principle: PineconeManager отвечает только за работу с векторной БД, bot.py – только за Telegram-интерфейс.

Dependency Inversion Principle: все внешние зависимости (API-ключи, URL, модели) передаются через конструктор или загружаются из .env, что позволяет легко подменять компоненты для тестирования.

⚠️ Примечания
Для работы требуется стабильное интернет-соединение для доступа к OpenAI API и Pinecone.

Модель OpenAI ограничена gpt-3.5-turbo-16k – не выше требуемого уровня.

Если вы используете прокси (proxyapi.ru), укажите его в OPENAI_BASE_URL.

Порог сходства можно регулировать в .env – уменьшайте для более агрессивного обновления или увеличивайте для создания большего числа уникальных записей.
