# 🤖 Персональный ассистент на Haystack + Telegram + Pinecone

Умный Telegram-бот, построенный на фреймворке **Haystack**, с использованием **Pinecone** для долговременной памяти и **OpenAI** для генерации ответов. Бот умеет:
- Отвечать на вопросы, используя контекст из истории диалога.
- Давать случайные факты о кошках.
- Показывать случайные изображения собак и описывать их породу (с помощью OpenAI).
- Сообщать текущую погоду в любом городе.

Все сообщения пользователя сохраняются в векторной базе Pinecone, что позволяет боту «помнить» предыдущие разговоры даже после перезапуска.

---

## 🚀 Возможности

| Команда / Запрос | Что делает |
|------------------|------------|
| `/start`, `/help` | Вывод приветствия и справки |
| `/clear` | Очистка локальной истории (контекст в Pinecone остаётся) |
| *«Расскажи факт о кошках»* | Возвращает случайный факт (catfact.ninja) |
| *«Покажи собаку»* | Отправляет случайное фото собаки и её описание (порода, история) |
| *«Какая погода в Москве?»* | Текущая температура и описание (OpenWeatherMap) |
| *«Что я говорил ранее о погоде?»* | Ищет в Pinecone ваши прошлые сообщения по теме и возвращает их |

---

## 🛠 Технологии

- **Haystack 3.0** – фреймворк для построения LLM-приложений.
- **OpenAI API** (через прокси `proxypi.ru`) – генерация текста и эмбеддингов.
- **Pinecone** – векторная база данных для хранения контекста.
- **PyTelegramBotAPI** – библиотека для Telegram-ботов.
- **Sentence-Transformers** (опционально) – локальный эмбеддер (не используется в текущей версии, оставлен как запасной вариант).

## 📦 Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
2. Создать и активировать виртуальное окружение
bash
python -m venv .venv
source .venv/bin/activate    # Linux/Mac
.venv\Scripts\activate       # Windows
3. Установить зависимости
bash
pip install -r requirements.txt
4. Настроить переменные окружения
Создайте файл .env в корне проекта со следующим содержимым:

env
OPENAI_API_KEY=sk-ваш-ключ
OPENAI_BASE_URL=https://api.proxypi.ru/v1
OPENAI_MODEL=gpt-3.5-turbo-16k
EMBEDDING_MODEL=text-embedding-3-small

PINECONE_API_KEY=ваш-ключ-pinecone
PINECONE_ENVIRONMENT=us-east-1   # или gcp-starter
PINECONE_INDEX_NAME=zerovpg06     # ваше имя индекса
PINECONE_HOST=https://ваш-индекс.svc.регион.pinecone.io

TELEGRAM_TOKEN=ваш-токен-бота
WEATHER_API_KEY=ваш-ключ-openweather
Важно: индекс в Pinecone должен иметь размерность 1536 (для модели text-embedding-3-small).

5. Запустить бота
bash
python telegram_bot.py
Бот начнёт опрос сообщений. Перейдите в Telegram и отправьте команду /start.

🧪 Запуск тестов
Юнит-тесты покрывают инструменты, контекстный менеджер и агента. Для их выполнения:

bash
python run_tests.py
Все тесты должны пройти успешно.
