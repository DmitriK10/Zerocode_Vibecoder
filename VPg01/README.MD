# 🤖 Телеграм-бот с памятью (Nemo / Dory)

Этот проект реализует двух телеграм-ботов на Python для демонстрации работы краткосрочной и долгосрочной памяти в языковых моделях (LLM). Боты используют OpenAI API (через прокси-сервис proxyapi.ru) с моделью **GPT-3.5-turbo**.

- **Nemo (MemoryBot)** – имеет как краткосрочную память (история диалога в оперативной памяти), так и долгосрочную память (сохранение тезисов в SQLite).
- **Dory (DoryBot)** – не имеет памяти, каждое сообщение обрабатывается изолированно.

Проект написан на Python с использованием библиотек `python-telegram-bot`, `openai`, `pydantic`, `sqlite3` и `httpx`. Код построен по принципам **Single Responsibility Principle** и **Dependency Inversion Principle**.

---

## 📦 Требования

- Python 3.10+
- Аккаунт в [proxyapi.ru](https://proxyapi.ru) (или другой прокси-сервис для OpenAI) с API-ключом.
- Телеграм-бот, зарегистрированный у [@BotFather](https://t.me/BotFather) (токен).

🤖 Команды бота (доступны только в Nemo)
/start – приветственное сообщение со списком команд.

/mytheses – показать все сохранённые тезисы для текущего пользователя.

/clear – очистить краткосрочную память (историю диалога).

/reset_all – очистить и краткосрочную, и долгосрочную память (удалить все тезисы из базы).

🧠 Как работает память
Краткосрочная память (ShortTermMemory)
Хранит последние N сообщений (по умолчанию 20) в оперативной памяти.

Используется для поддержания контекста в текущем диалоге.

Очищается командой /clear.

Долгосрочная память (DatabaseManager)
Хранит тезисы (ключевые факты) из каждого ответа модели в SQLite.

Тезисы извлекаются при каждом новом сообщении и добавляются в системный промпт, что позволяет модели «помнить» пользователя даже после перезапуска бота.

Очищается командой /reset_all (вместе с краткосрочной).

📝 Примечания
Для работы требуется стабильный доступ к api.telegram.org и к выбранному прокси-сервису OpenAI.

Если вы используете корпоративный прокси, раскомментируйте строки HTTP_PROXY / HTTPS_PROXY в .env и укажите корректные параметры.

Модель ограничена GPT-3.5 в соответствии с заданием (не выше).

При ошибках API (например, исчерпание баланса) бот возвращает понятное сообщение пользователю и не сохраняет мусорные тезисы.

🧪 Тестирование
Отправьте боту несколько сообщений, например:

«Расскажи про Санкт-Петербург»

«А что посмотреть там?»

/mytheses – вы увидите сохранённые тезисы (например, «Пользователь интересуется Санкт-Петербургом»).

Затем отправьте /clear и повторите диалог – увидите, что краткосрочная память очищена, но тезисы из БД сохранились (если не вызывать /reset_all).
