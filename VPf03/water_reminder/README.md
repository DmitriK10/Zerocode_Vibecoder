# Water Reminder – активное напоминание о питье воды

Этот проект создан в рамках урока по промпт-инжинирингу. Он демонстрирует, как:
- составить управляемый промпт для LLM;
- получить структурированный JSON-ответ;
- улучшить промпт с помощью few-shot;
- превратить результат в полезный программный артефакт.

Готовый план гидратации загружается из JSON-файла, а программа автоматически планирует и отправляет **всплывающие напоминания** в указанные часы.

---

## Как это работает

1. В файле `data/plan.json` хранится план в формате:
   ```json
   {
     "title": "...",
     "steps": ["... (10:00) ...", "... (14:00) ..."],
     "notes": ["...", "...", "..."]
   }
   
Программа извлекает из каждого шага временные метки в формате (ЧЧ:ММ).

С помощью библиотеки schedule для каждого найденного времени создаётся ежедневное задание.

В заданное время вызывается метод send выбранного нотификатора.

По умолчанию используются всплывающие уведомления Windows (через win10toast). Если библиотека не установлена, программа переключается на вывод в консоль.

Установка и запуск
1. Клонируйте репозиторий (или скопируйте файлы)
Проект имеет следующую структуру:

text
water_reminder/
├── data/
│   └── plan.json
├── src/
│   ├── main.py
│   ├── loader.py
│   ├── formatter.py
│   ├── notifier.py
│   └── scheduler.py
├── requirements.txt
└── README.md
2. Установите зависимости
В терминале (PowerShell) перейдите в корневую папку проекта и выполните:

powershell
pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org -r requirements.txt
Если у вас установлен Anaconda и возникают SSL-ошибки, используйте:

powershell
conda install -c conda-forge schedule
pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org win10toast
3. Запустите программу
powershell
python src/main.py
Вы увидите вывод плана в консоли и сообщения о запланированных напоминаниях. Программа будет работать в фоне до нажатия Ctrl+C.

Настройка плана
Вы можете изменить data/plan.json под свои нужды. Главное – сохранять структуру и указывать время в формате (ЧЧ:ММ) внутри шагов. Например:

json
{
  "title": "Мой план гидратации",
  "steps": [
    "Проснувшись, выпей стакан воды (07:30).",
    "На работе пей по 200 мл каждый час (09:00, 10:00, 11:00, 12:00).",
    "После обеда ещё 300 мл (14:00).",
    "Вечером за час до сна – травяной чай (21:00)."
  ],
  "notes": [
    "Следи за цветом мочи – он должен быть светлым.",
    "Если чувствуешь голод, сначала выпей воды."
  ]
}
Расширение и замена способа уведомлений
Класс Notifier является абстрактным. Вы можете реализовать свой собственный класс, например, для отправки в Telegram, и передать его в Scheduler в файле main.py. Пример:

python
class TelegramNotifier(Notifier):
    def send(self, message: str):
        # ваш код отправки в Telegram
        pass
И затем в main.py:

python
notifier = TelegramNotifier()   # вместо WinToastNotifier


Сравнение версий промптов
Версия	Особенности
Первая (без few-shot)	Общие рекомендации, нет конкретных временных меток.
Улучшенная (с few-shot)	Чёткие временные интервалы, научное обоснование, конкретные объёмы.
Улучшенный промпт дал более практичный и структурированный план, что подтверждает эффективность few-shot подхода.
