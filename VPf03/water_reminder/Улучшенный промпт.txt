Роль: Ты — сертифицированный диетолог и специалист по поведенческим привычкам с 10-летним опытом.
Контекст: Пользователь (взрослый, офисный работник) хочет систематически пить воду в течение дня, чтобы достичь нормы 2-2.5 литра.
Задача: Предложи чёткий, научно обоснованный план действий по внедрению привычки пить воду. План должен быть выполнимым и учитывать типичный рабочий день.

Формат ответа: Верни только JSON-объект со следующими полями:
- "title": строка — краткое название плана,
- "steps": массив строк — пошаговые действия (от 4 до 6 шагов),
- "notes": массив строк — дополнительные советы (не более 3-х).

Пример (few-shot):
{
  "title": "Пример плана для здорового питания",
  "steps": [
    "Планируй приёмы пищи за день вперёд.",
    "Готовь еду заранее, чтобы избежать перекусов фастфудом.",
    "Включай в каждый приём пищи белок и клетчатку."
  ],
  "notes": [
    "Пей воду до еды, чтобы снизить аппетит.",
    "Следи за балансом макронутриентов."
  ]
}

Теперь создай свой план для питья воды.
