VK Bot Consultant for Designer

📖 Описание проекта
Этот проект представляет собой VK‑бота-консультанта для дизайнера, который помогает клиентам получать информацию об услугах, ценах, портфолио и контактных данных. Бот поддерживает:

📋 Каталог услуг — список дизайнерских услуг с описаниями.

💰 Прайс-лист — стоимость каждой услуги.

🖼 Портфолио — ссылка на работы.

📞 Контакты — телефон и email.

📝 Заявки — сбор номера телефона с валидацией и сохранение в файл leads.txt.

Код написан на Python с использованием библиотеки vk-api, реализована простая система состояний (FSM) с сохранением в JSON, а также тесты на pytest.

🚀 Основные возможности
Интерактивные клавиатуры для удобной навигации.

Обработка ошибок VK API и автоматическое переподключение LongPoll.

Персистентное хранение состояний между перезапусками (через JSON).

Валидация номера телефона с помощью регулярных выражений.

Тестовое покрытие ключевой логики (12 тестов).

Чистая архитектура с разделением на модули.

🛠 Установка и настройка
1. Клонирование репозитория
bash
git clone <ссылка на репозиторий>
cd vk_consultbot
2. Создание виртуального окружения
bash
python -m venv venv
Активируйте окружение:

Windows (PowerShell):

bash
.\venv\Scripts\Activate.ps1
Windows (cmd):

bash
venv\Scripts\activate
Linux / macOS:

bash
source venv/bin/activate
3. Установка зависимостей
bash
pip install -r requirements.txt
4. Настройка переменных окружения
Скопируйте файл .env.example в .env и заполните реальными данными:

text
VK_TOKEN=ваш_токен_группы_ВКонтакте
DESIGNER_PHONE=+7-XXX-XXX-XX-XX
DESIGNER_EMAIL=designer@example.com
PORTFOLIO_LINK=https://www.behance.net/yourportfolio
Важно: токен должен быть от группы или от пользователя с правами на отправку сообщений. Убедитесь, что у сообщества включена возможность отправлять сообщения.

▶️ Запуск бота
bash
python main.py
После запуска бот начнёт слушать события LongPoll и отвечать на сообщения. Остановить бота можно нажатием Ctrl+C.

🧪 Запуск тестов
Все тесты находятся в папке tests/. Запустите их командой:

bash
pytest tests/ -v
При успешном выполнении вы увидите зелёный вывод со списком всех прошедших тестов.

🧠 Архитектура и логика работы
VKClient — инициализирует соединение с VK API через LongPoll, получает новые сообщения и передаёт их в MessageHandler.

MessageHandler — анализирует текст, проверяет состояние пользователя (если ожидается номер телефона), валидирует ввод, вызывает соответствующие методы для отправки ответов.

FSMStorage — управляет состояниями пользователей (ожидание номера) с автоматическим сохранением в JSON-файл.

Catalog — хранит предопределённый список услуг и предоставляет методы для их получения.

Config — использует dataclass для типизированной загрузки переменных окружения.

Обработка ошибок в VKClient позволяет боту автоматически переподключаться при обрыве LongPoll-соединения.
