# Кинотека – MCP-сервер + Telegram бот

## Описание
Проект представляет собой систему, состоящую из:
- **MCP-сервера** (FastAPI), который предоставляет набор инструментов для работы с базой данных фильмов.
- **Telegram-бота**, который через LLM (GPT-4o-mini через ProxyAPI) анализирует запрос пользователя, определяет необходимый инструмент, вызывает его через MCP-сервер и возвращает результат.

### Основные функции
- 🎬 **Работа с фильмами:**  
  - `list_movies` – показать все фильмы.  
  - `find_movie_by_title` – поиск по названию (частичное совпадение).  
  - `find_movies_by_director` – поиск по режиссёру.  
  - `find_movies_by_genre` – поиск по жанру.  
  - `add_movie` – добавить новый фильм (название, режиссёр, жанр, год, рейтинг – опционально).  
  - `delete_movie` – удалить фильм по ID.  
  - `update_movie_rating` – обновить рейтинг.  
  - `get_top_movies` – показать топ-N по рейтингу (по умолчанию 5).  
  - `get_random_movie` – получить случайный фильм.

- 🧮 **Дополнительные инструменты:**  
  - `calculate` – безопасный калькулятор (поддерживает +, -, *, /, **, скобки).  
  - `get_weather` – погода в любом городе (Open-Meteo).  
  - `get_exchange_rate` – курс валют (exchangerate.host).  
  - `generate_qr` – генерация QR-кода из текста.  
  - `web_search` – поиск в интернете (DuckDuckGo).

## Требования
- Python 3.9+
- VPN или прокси для доступа к Telegram API (если требуется).
- Аккаунт OpenAI (или доступ к ProxyAPI).

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <url-репозитория>
cd VPf08

### 2. Создание виртуального окружения (рекомендуется)
bash
python -m venv venv
source venv/bin/activate   # для Linux/Mac
venv\Scripts\activate      # для Windows

### 3. Установка зависимостей
Для MCP-сервера:

bash
cd mcp_server
pip install -r requirements.txt
cd ..
Для Telegram-бота:

bash
cd telegram_bot
pip install -r requirements.txt
cd ..

### 4. Настройка .env
Создайте файл .env в корне проекта со следующим содержимым (подставьте свои токены):

env
# Telegram Bot
BOT_TOKEN=ваш_токен_бота

# OpenAI (через ProxyAPI)
OPENAI_API_KEY=ваш_ключ_ProxyAPI
OPENAI_BASE_URL=https://openai.api.proxyapi.ru/v1

# MCP сервер (локальный)
MCP_SERVER_URL=http://127.0.0.1:8000

# Прокси для Telegram (если требуется)
# PROXY_HOST=proxy.example.com
# PROXY_PORT=1080
# PROXY_TYPE=http   # или socks5

### 5. Запуск
Запустите MCP-сервер (в отдельном терминале):

bash
python -m mcp_server.server
Сервер будет доступен по адресу http://127.0.0.1:8000.

Запустите Telegram-бота (в другом терминале):

bash
python -m telegram_bot.bot

### 6. Проверка
Откройте Telegram, найдите бота по токену и отправьте команду /start.
Теперь вы можете отправлять запросы на русском языке.
