# Flask User API

Безопасное REST API для управления пользователями, реализованное на Flask с использованием SQLite.

## Возможности

- **Добавление пользователя** – `POST /adduser` (принимает JSON `{"name": "..."}`)
- **Получение пользователя по ID** – `GET /user/<id>`
- **Активация пользователя** – `GET/POST /activate/<id>` (потокобезопасно, возвращает список активных)
- **Фоновая задача** – `GET /slow` (запускает тяжёлую задачу в отдельном потоке, возвращает 202)
- **Обработка ошибок** – `GET /wrong` (демонстрирует перехват исключения деления на ноль, возвращает 500)

Все эндпоинты используют параметризованные SQL-запросы, что исключает SQL-инъекции. Работа с БД обёрнута в контекстный менеджер Flask (`g`), соединение автоматически закрывается после запроса.

## Запуск локально (без Docker)

### 1. Установка Python и зависимостей

Убедитесь, что у вас установлен **Python 3.8 или выше**.

Клонируйте репозиторий и перейдите в корневую директорию проекта.

Создайте виртуальное окружение (рекомендуется):
```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
# или
venv\Scripts\activate         # Windows
Установите зависимости:

bash
pip install -r requirements.txt
2. Запуск сервера
bash
python api.py
Сервер запустится на http://0.0.0.0:8080. В терминале вы увидите:

text
* Running on all addresses (0.0.0.0)
* Running on http://127.0.0.1:8080
3. Проверка работоспособности
Оставьте сервер работающим в одном терминале. В другом терминале выполните:

bash
python test_endpoints.py
Ожидаемый вывод:
Testing API...
All tests passed!
Вы также можете вручную отправлять запросы через curl, браузер или Postman.

### Запуск через Docker
1. Сборка образа
Из корневой директории проекта (где лежит Dockerfile):

bash
docker build -t user-api .
2. Запуск контейнера
bash
docker run --rm -p 8080:8080 user-api
API будет доступно по адресу http://localhost:8080.

3. Тестирование в контейнере
Тесты можно запускать с хоста, так как порт проброшен:

bash
python test_endpoints.py
Если вы хотите выполнить тесты внутри контейнера, можно зайти в него:

bash
docker exec -it <container_id> python test_endpoints.py
Публикация образа в Docker Hub
Войдите в Docker Hub:

bash
docker login
Присвойте тег:

bash
docker tag user-api yourusername/user-api:latest
Отправьте образ:

bash
docker push yourusername/user-api:latest
Развёртывание на удалённом сервере
На сервере (Ubuntu/Debian) с установленным Docker выполните:

bash
docker pull yourusername/user-api:latest
docker run -d --restart unless-stopped -p 8080:8080 yourusername/user-api:latest
После этого API будет доступно по публичному IP вашего сервера на порту 8080.

OpenAPI документация

Swagger UI

Postman

Insomnia

Любой другой инструмент, поддерживающий OpenAPI

Это облегчает тестирование и генерацию клиентских SDK.

Тестирование с помощью скрипта
Скрипт test_endpoints.py последовательно проверяет все эндпоинты:

создаёт пользователя,

получает его по ID,

активирует его,

запускает фоновую задачу,

проверяет обработку ошибки.

При успешном прохождении всех проверок выводится All tests passed!.
