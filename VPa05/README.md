# PDF Generator

## Описание
Скрипт для генерации PDF-отчётов из данных (например, из CSV или JSON). Использует библиотеку ReportLab или FPDF.

## Цель проекта
Научиться создавать структурированные PDF-документы программно.

## Результаты
- Генерация отчётов с таблицами, заголовками и графиками (если есть).
- Поддержка нескольких форматов входных данных.
- Настройка стилей (шрифты, цвета).

## Использованные технологии
- **Python:** ReportLab (или FPDF)
- **Дополнительно:** Pandas (опционально)

## Установка и запуск
1. Перейдите в папку `VPa05/pdf_generator`.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
Запустите скрипт с примером данных:
