🤖 Бот для записи на IT-консультации
ВК-бот с искусственным интеллектом для автоматизации записи на консультации. Бот приветствует пользователей по имени, отвечает на вопросы с помощью AI (через ProxyAPI), позволяет записаться на консультацию в формате «Тема | Дата | Контакт», показывает FAQ и список ваших записей.

✨ Возможности
Персонализированное приветствие – бот узнаёт имя пользователя через VK API.

Интерактивная клавиатура – кнопки для быстрого доступа к основным функциям.

Запись на консультацию – парсинг сообщения в формате Тема | ДД-ММ-ГГГГ ЧЧ:ММ | Контакт с валидацией даты.

FAQ – список часто задаваемых вопросов.

Просмотр записей – пользователь может посмотреть свои активные заявки.

AI-помощник – ответы на произвольные вопросы через модель GPT (ProxyAPI).

Сохранение заявок – данные хранятся в JSON-файле, не теряются при перезапуске.

Логирование – подробное логирование ошибок и событий для отладки.

🛠 Технологический стек
Python 3.11+ – основной язык.

VKBottle 4.10+ – библиотека для работы с VK API.

aiohttp – асинхронные HTTP-запросы.

ProxyAPI – провайдер для OpenAI-совместимых моделей (используется gpt-3.5-turbo-16k).

pytest + pytest-asyncio – модульное тестирование.

python-dotenv – управление переменными окружения.

📦 Установка и запуск
1. Клонирование репозитория
bash
git clone <your-repo-url>
cd vk_consultation_bot
2. Создание и активация виртуального окружения
bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/MacOS
source venv/bin/activate
3. Установка зависимостей
bash
pip install -r requirements.txt
4. Настройка переменных окружения
Скопируйте .env.example в .env:

bash
cp .env.example .env
Отредактируйте .env, заполнив своими данными:

text
VK_TOKEN=ваш_токен_сообщества
OPENAI_API_KEY=ваш_ключ_от_proxyapi
OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1
OPENAI_MODEL=gpt-3.5-turbo-16k
5. Запуск бота
bash
python bot.py
После запуска в консоли появится сообщение: 🚀 Бот запущен и ожидает сообщений...

6. Остановка бота
Нажмите Ctrl+C – бот корректно завершит работу.

🔧 Настройка сообщества ВКонтакте
Перейдите в настройки вашего сообщества → «Работа с API».

Создайте ключ доступа с правами:

«Разрешить приложению доступ к управлению сообществом»

«Разрешить приложению доступ к сообщениям сообщества»

Скопируйте полученный токен в переменную VK_TOKEN в .env.

Включите LongPoll API (вкладка «Long Poll API» → переключатель «Включен»).

Убедитесь, что в настройках сообщества включены сообщения.

🧪 Тестирование
Для запуска тестов выполните:

bash
pytest -v
Тесты проверяют:

Создание и получение записей (AppointmentManager)

Ответы AI-клиента (с использованием моков)

🗺 Как пользоваться ботом
Напишите боту «Начать» – он поприветствует вас по имени и покажет клавиатуру.

Нажмите кнопки:

Записаться на консультацию – бот объяснит формат сообщения.

FAQ – покажет ответы на частые вопросы.

Мои записи – список ваших заявок.

Помощь – краткая справка по командам.

Для записи отправьте сообщение в формате:
Тема консультации | ГГГГ-ММ-ДД ЧЧ:ММ | Контакт
Например:
Разработка микросервисов | 2026-08-20 15:00 | +79991234567

Любое другое сообщение (не команда) бот отправит в AI и вернёт ответ.
