# Task Bot — Телеграм-бот для управления задачами

## Описание
Телеграм-бот, который позволяет создавать, просматривать и удалять задачи прямо в чате. Использует Aiogram и SQLite для хранения данных.

## Цель проекта
Изучить создание телеграм-ботов с использованием асинхронного фреймворка Aiogram и работы с базами данных.

## Результаты
- Команды: `/start`, `/new`, `/list`, `/done`, `/delete`.
- Хранение задач в SQLite с привязкой к пользователю.
- Инлайн-клавиатуры для удобного управления.
- Обработка ошибок и логирование.

## Использованные технологии
- **Язык:** Python 3.10
- **Библиотеки:** Aiogram, SQLite3
- **Инструменты:** python-dotenv
