# Discount Calculator

## Описание
Консольное приложение для расчёта скидок на товары. Позволяет вводить данные о товарах, применять различные типы скидок (процентные, фиксированные) и сохранять историю расчётов в базу данных SQLite.

## Цель проекта
Отработать навыки ООП, работы с базами данных (SQLite) и создания интерактивных CLI-приложений.

## Результаты
- Реализованы классы для товаров и корзины.
- Поддержка нескольких типов скидок.
- Сохранение истории расчётов с возможностью просмотра.
- Интерфейс командной строки с меню.

## Использованные технологии
- **Язык:** Python 3.10
- **База данных:** SQLite (sqlite3)
- **Дополнительно:** ООП, модуль `datetime`

## Установка и запуск
1. Клонируйте репозиторий (или перейдите в папку `VPa06/DiscountCalculator`).
2. Убедитесь, что у вас установлен Python.
3. Запустите приложение:
   ```bash
   python main.py
Следуйте инструкциям в меню.
