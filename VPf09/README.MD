# VPf09 – Telegram-бот с LLM, генерацией изображений и SQLite-памятью

## Описание

Проект представляет собой Telegram-бота, интегрированного с OpenAI (через ProxyAPI). Бот обладает следующими возможностями:

- **Работа с LLM:** отвечает на вопросы, запоминает контекст диалога (история хранится в SQLite).
- **Выбор ролевой модели:** через команду `/mode` можно переключать системные промпты (например, "Обычный помощник", "Разработчик", "Аналитик").
- **Генерация изображений:** команда `/image <описание>` создаёт изображение через бесплатный API [pollinations.ai](https://pollinations.ai).
- **Расчёт стоимости:** каждый запрос к OpenAI логируется, показывается стоимость в рублях (курс USD/RUB от ЦБ РФ с кэшированием).
- **Повторные попытки:** при сетевых ошибках выполняется до 3 повторных попыток с экспоненциальной задержкой.
- **Постоянная память:** история диалогов сохраняется в SQLite (`history.db`) и не теряется при перезапуске бота.

## Технологии

- Python 3.10+
- `aiogram` – работа с Telegram Bot API
- `openai` – взаимодействие с OpenAI-compatible API (ProxyAPI)
- `sqlite3` – хранение истории
- `aiohttp` – асинхронные HTTP-запросы к pollinations.ai
- `requests` – синхронные запросы к ЦБ РФ (курс валют)

Примечания

## Для работы необходим доступ к Telegram API и OpenAI (через ProxyAPI). При отсутствии прямого доступа используйте прокси.

Курс валют кэшируется на 10 минут для снижения нагрузки на API ЦБ РФ.

Генерация изображений использует сервис pollinations.ai (бесплатно, без регистрации).
