# Система бронирования столиков (учебный проект)

Архитектура построена с соблюдением принципов SOLID.

## Установка и запуск

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте: `source venv/bin/activate` (Linux) или `venv\Scripts\activate` (Windows)
4. Установите зависимости: `pip install -r requirements.txt`
5. Создайте файл `.env` по образцу `.env.example`, указав свои параметры подключения к PostgreSQL.
6. Убедитесь, что база данных `booking` создана в PgAdmin.
7. Запустите приложение: `python app.py`

## Функциональность

- **Пользователи**: добавление, редактирование, удаление, просмотр.
- **Столы**: добавление, редактирование, удаление, просмотр.
- **Бронирования**: создание с проверкой доступности стола на выбранное время, редактирование, отмена.
- Проверка доступности стола перед созданием бронирования.

## Структура

- `models/` – модели данных (User, Table, Booking) с аннотациями для автоматического создания таблиц.
- `database_driver.py` – абстрактный интерфейс драйвера БД.
- `postgres_driver.py` – реализация для PostgreSQL с поддержкой datetime.
- `backend.py` – бизнес-логика (CRUD + проверка доступности + вспомогательные функции).
- `app.py` – графический интерфейс на tkinter с полным CRUD.
- `config.py` – загрузка переменных окружения.
