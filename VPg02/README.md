# 🤖 Бот с векторной памятью (VPG02)

Этот проект реализует **Телеграм-бота с долговременной памятью** на основе векторных баз данных. Бот запоминает факты, которые вы ему сообщаете, и использует их как контекст при ответах на ваши вопросы.  

В основе лежат:
- **Pinecone** – векторная база данных для хранения и поиска эмбеддингов.
- **OpenAI Embeddings** (через ProxyAPI) – преобразование текста в векторы.
- **GPT-3.5-turbo** – генерация ответов с учётом найденных воспоминаний.
- **PyTelegramBotAPI** – интерфейс для общения в Telegram.

🧠 Как работает бот
Запоминание фактов

Автоматически при наличии ключевых слов (запомни, важно, мой, я люблю, я хочу и т.д.).

Вручную командой /save <текст>.

Текст преобразуется в эмбеддинг и сохраняется в Pinecone с метаданными (user_id, text, category, importance).

Поиск воспоминаний
Перед генерацией ответа бот:

Преобразует вопрос пользователя в эмбеддинг.

Ищет в Pinecone топ‑10 векторов, наиболее похожих по смыслу (фильтр по user_id).

Извлекает тексты найденных воспоминаний.

Генерация ответа
Бот формирует системный промпт, добавляет в него контекст из воспоминаний и вопрос пользователя, затем отправляет запрос к gpt-3.5-turbo-16k (через ProxyAPI). Ответ возвращается в Telegram.

🏗️ Соблюдение принципов SOLID
Single Responsibility (SRP)
Каждый класс отвечает за одну задачу:

EmbeddingService – только получение эмбеддингов.

PineconeService – только работа с Pinecone.

Searcher – поиск и вывод.

DataLoader – загрузка данных.

bot.py – логика бота и связывание сервисов.

Dependency Inversion (DIP)
Высокоуровневые модули (bot.py, DataLoader, Searcher) не зависят от конкретных реализаций – они получают экземпляры сервисов через конструкторы. Это позволяет легко заменить эмбеддинг-модель или базу данных без изменения остального кода.

📌 Примечания
Для работы бота требуется доступ к интернету (Telegram API, Pinecone API, OpenAI API).

Если возникают SSL-ошибки, убедитесь, что у вас установлен пакет certifi, и в коде бота прописано os.environ['SSL_CERT_FILE'] = certifi.where().

Все пути к файлам в коде строятся абсолютно через os.path.join, что гарантирует корректную работу из любой папки.
